# ⏱ 시간 누적 타이머

카테고리별 누적 시간을 관리할 수 있는 카운트다운 타이머 웹 앱입니다.

## 주요 기능

- **카운트다운 타이머** — 분/초 단위로 시간을 설정하고 시작/일시정지/초기화 가능
- **알람** — 타이머 완료 시 Web Audio API로 알람음 3회 재생 (별도 오디오 파일 불필요)
- **시간 누적** — 타이머 완료 시 선택한 카테고리에 해당 시간이 자동 누적
- **카테고리 관리** — 카테고리 추가/삭제, 누적 시간 개별 초기화
- **영구 저장** — localStorage를 사용해 새로고침 이후에도 데이터 유지
- **다크모드** — 라이트/다크 테마 전환 지원
- **반응형** — 모바일(세로 배치) / 데스크톱(좌우 분할) 레이아웃

## 기술 스택

## 프로젝트 구조

```
src/
├── pages/
│   ├── _app.js           # ThemeProvider 설정
│   └── index.js          # 메인 페이지 (타이머 + 카테고리 조합)
├── components/
│   ├── layout.js         # 헤더 + 다크모드 토글 래퍼
│   ├── DarkModeToggle.js # 다크/라이트 전환 버튼
│   ├── timer/
│   │   ├── TimerCircle.js   # SVG 원형 프로그레스 + 시간 표시
│   │   ├── TimerSetup.js    # 분/초 입력 + 카테고리 선택
│   │   └── TimerControls.js # 시작/일시정지/초기화 버튼
│   └── categories/
│       └── CategoryPanel.js # 카테고리 추가·삭제 + 누적 시간 목록
├── hooks/
│   ├── useTimer.js       # 카운트다운 로직, 알람, 완료 콜백
│   └── useCategories.js  # 카테고리 CRUD, localStorage 동기화
└── styles/
    └── globals.css       # Tailwind 베이스 + 전역 스타일
```

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:3000)
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start
```

## 사용 방법

1. **시간 설정** — 분/초 입력란에 원하는 시간을 입력합니다.
2. **카테고리 선택** — 드롭다운에서 시간을 누적할 카테고리를 선택합니다.
3. **시작** — 시작 버튼을 누르면 카운트다운이 시작됩니다.
4. **완료** — 타이머가 0이 되면 알람이 울리고, 설정한 시간이 선택한 카테고리에 자동으로 누적됩니다.
5. **카테고리 관리** — 우측 패널에서 카테고리를 추가하거나 삭제할 수 있습니다. 누적 시간만 초기화하려면 카테고리 옆 리셋 아이콘을 클릭합니다.
